# FeedBackify – DevOps Powered Student Feedback System

FeedBackify is a Flask-based Student Feedback System built and deployed using a complete DevOps workflow including Infrastructure as Code, Containerization, CI/CD automation, Cloud hosting, and Monitoring.

---

## 🚀 Live Application

🔗 http://3.82.22.18:5000

---

## 🏗️ Architecture

Developer → GitHub → Jenkins (CI/CD) → Docker → AWS EC2 → Prometheus → Grafana

---

## 🛠️ Tech Stack

- Backend: Python (Flask)
- Database: SQLite
- Containerization: Docker
- Infrastructure: Terraform
- Cloud: AWS EC2
- CI/CD: Jenkins
- Monitoring: Prometheus + Grafana
- Version Control: Git & GitHub
